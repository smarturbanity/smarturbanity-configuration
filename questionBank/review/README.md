# Question wording review

This technical baseline migrates the 21 questionnaires from local main f5c9e03b768c9c2b6ab12b9e17b8f63a8ce3516b into the question bank without changing prompts, answer options, ordering, branching or required flags. Historical answer-key aliases are added as technical metadata.

The reference collection is the baseline bank with that metadata; source.json identifies the original main form bytes and maps each retained variant. The separate citymaas/questionnaire-content branch holds proposed wording, translations and composition changes. Review drafts and marks belong in reusable exported review files.
