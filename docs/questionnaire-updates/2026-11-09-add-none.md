# Standard “None of these” answer

Decision: use the application's `add_none: true` property instead of repeating the
standard answer in each question's options. It adds a choice for the respondent;
it never chooses an answer on their behalf.

Twenty-eight source question occurrences in 22 forms now use the flag. The car-use
matrix adds its exclusive `none` row through the same property instead of keeping
it in the car-use catalogue. Selecting it requires no frequency or alternative.
Personalized negative answers with different wording or stored values remain explicit.

Stored option value `none`, matrix answer `{ "none": true }`, other answer values,
matrix columns and all eight translation dictionaries are preserved. Current
question and form revisions advance; composed surveys are rebuilt with new versions.
No collected answers are rewritten.

The configuration requires an application supporting the new ordinary-question
flag before it is published. These changes are local and do not publish either
the application or its questionnaires. The corresponding PlanEasy update adds 27
selected revisions and preserves the 2,613 preceding historical snapshots.

Verification: effective-option and matrix-row comparisons against the previous
configuration pass for all 28 occurrences. Bundle verification passes for 51 source
forms, 16 bundles, 258 composed questions, 38 catalogue entries and eight languages.
The [migration manifest](2026-11-09-add-none.json) records the affected revisions.
