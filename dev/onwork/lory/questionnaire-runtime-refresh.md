# Local questionnaire package

Runtime configuration and forms use one commit of this branch. Package paths are
local. Unused installation manifests and their export step are removed; the
exporter accepts one revision, preventing mixed configuration and questionnaires.
No retired forms or compatibility code is added. Commands and source checks
are recorded in [the delivery notes](../../../docs/questionnaire-runtime-refresh.md).

Application verification and publication belong to the application coordinator.
Keep active verification worktrees until that coordinator releases them. No push.
